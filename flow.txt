# WeighCert User Workflow

Before setup, copy `.env.example` to `.env` and set strong local credentials. The `.env` file is ignored by Git; never commit it. The setup command creates the admin account using `DEMO_ADMIN_PASSWORD`, and demo seeding uses `DEMO_INSPECTOR_PASSWORD` and `DEMO_OFFICER_PASSWORD`.

## 1. System Setup & Weights (Admin)

1. Sign in at `http://127.0.0.1:8000/login/` as `admin@weighcert.gov.in`, using the local `DEMO_ADMIN_PASSWORD`.
2. From the sidebar:
   - **Test Weights (`/weights/`):** View, add, or manage OIML R 111 reference weights and calibration due dates.
   - **Settings (`/settings/`):** Configure lab name, accreditation number, report prefix, OIML rule-set tables, and Inspector and Officer accounts.
3. Log out.

## 2. Register Instrument & Run Inspection (Inspector)

1. Sign in as `inspector.singh@gov.in`, using the local `DEMO_INSPECTOR_PASSWORD`.
2. **Dashboard (`/`):** View active instruments, draft/returned sessions, and pending work.
3. **Instruments (`/instruments/`):** Browse registered instruments or add one, validated against OIML Tables 3 and 4.
4. **Start Inspection (`/tests/new/`):** Select an instrument and complete the seven-step inspection wizard:
   - Conditions and weights
   - Zero check
   - Accuracy test
   - Repeatability test
   - Eccentricity test
   - Conditional tests
   - Remarks and summary
5. Submit for approval; the session moves from `Draft` to `Submitted`.
6. Log out.

## 3. Review, Approve & Issue Certificate (Officer)

1. Sign in as `officer.sharma@gov.in`, using the local `DEMO_OFFICER_PASSWORD`.
2. Open the submitted session from the dashboard to reach its review screen.
3. Return it for correction with remarks, or approve and issue the report. Issuance generates a sequential report number, immutable snapshot, QR verification token, and downloadable PDF.
4. View the report preview, download its PDF, or browse issued reports in the archive. Corrections to issued reports create a new revision.

## 4. Public Verification

1. Open `http://127.0.0.1:8000/verify/` or follow the QR code on an issued PDF.
2. Enter a report number or verification token.
3. The portal checks the stored record and snapshot to report whether the certificate is authentic and intact, superseded, or altered.
